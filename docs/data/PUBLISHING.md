# Curated dataset publication

The public data bundle is intentionally smaller than the local inventory. It
contains the reproducibility-critical C14 and SM Bakta/Baktfold GBFF and FAA
inputs, Kofam/eggNOG evidence tables, restored/enriched GBFF outputs and their
sidecar manifests, plus the BK71A structural-only restored GBFF.

The exact file set is generated by:

```text
python tools/build_published_dataset_manifest.py \
  docs/data/MANIFEST.json docs/data/PUBLISHED-MANIFEST.json
python tools/render_dataset_manifest_tsv.py \
  docs/data/PUBLISHED-MANIFEST.json docs/data/PUBLISHED-MANIFEST.tsv
python tools/validate_dataset_manifest.py docs/data/PUBLISHED-MANIFEST.json
```

The curated artifacts are published under the owner's `CC-BY-4.0` grant (see
[`DATA-LICENSE-CC-BY-4.0.txt`](../../DATA-LICENSE-CC-BY-4.0.txt)) and stored
with Git LFS. Their scientific status remains
`historical_unverified` where producer/database metadata or independent
lineage has not yet been confirmed. This is a distribution decision, not a
claim that every derived annotation is biologically validated.

BK71A has no pristine Bakta FAA/evidence bundle in this checkout. Its published
artifact is therefore structural-only and must not be used as evidence of a
functional rerun.

The local `MANIFEST.json` remains a complete inventory of the 77 materialized
files, including artifacts intentionally excluded from publication. The
curated `PUBLISHED-MANIFEST.json` is the clean-clone validation authority.
